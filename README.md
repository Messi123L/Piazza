## 📌 نظرة عامة عن المشروع (Overview)

تطبيق ويب حديث وعالي الأداء مخصص لمكتب المحاماة **STUDIO LEGALE PIAZZA** بإشراف **الأستاذ المحامي ماسيميليانو (Avv. Massimiliano Piazza)**، موجه لخدمة الجالية والمواطنين والمستثمرين المقيمين في **المغرب أو إيطاليا**.

يقدم التطبيق واجهة مستخدم احترافية تدعم اللغة العربية بالكامل مع الاتجاه من اليمين إلى اليسار (RTL)، مع إمكانية استعراض الخدمات القانونية العشرة المعتمدة، معرفة أوقات العمل الرسمية مباشرة، حجز استشارات قانونية، والتواصل الفوري عبر الواتساب ورقم الهاتف المباشر.

## ⚖️ الخدمات القانونية الـ 10 المعتمدة (Legal Practice Areas)

1. **01. الهجرة وتصاريح الإقامة (Permesso di Soggiorno)**  
   تجديد وتعديل الإقامات، عقود العمل، لم الشمل العائلي، والدفاع ضد قرارات الرفض أو الترحيل.
2. **02. الجنسية الإيطالية (Cittadinanza Italiana)**  
   تقديم ومتابعة ملفات الجنسية عن طريق الإقامة (10 سنوات) أو الزواج، وتسريع الإجراءات المتأخرة.
3. **03. الدراسة والفيزا الجامعية (Studio e Visto)**  
   إجراءات التسجيل الجامعي، معادلة الشهادات (Dichiarazione di Valore)، وتأشيرات الطلاب.
4. **04. قانون العمل والمستحقات العمالية (Diritto del Lavoro & TFR)**  
   الطعن في الفصل التعسفي، استرجاع مكافأة نهاية الخدمة (TFR)، وساعات العمل غير المصرح بها.
5. **05. تعويضات حوادث السير (Incidenti Stradali)**  
   تحصيل أقصى تعويض مالي من شركات التأمين عن الأضرار المادية والجسدية الناتجة عن حوادث الطرق.
6. **06. حوادث وإصابات العمل (Infortuni sul Lavoro - INAIL)**  
   متابعة ملفات العجز الطبي والتعويضات الدائمة لدى مؤسسة التأمين ضد حوادث العمل.
7. **07. قانون الأسرة، الزواج والطلاق، والميراث (Diritto di Famiglia)**  
   قضايا الطلاق المدني، النفقة، حضانة الأطفال، وتوثيق الزواج المختلط وتقسيم التركات.
8. **08. الوثائق، التصديقات والترجمة المحلفة (Traduzioni e Legalizzazioni)**  
   الترجمة القانونية المحلفة (Traduzione Giurata)، وأبوستيل (Apostille) وتصديق الوثائق الرسمية.
9. **09. تأسيس الشركات، التجارة والاستثمار (Società e Investimenti)**  
   تأسيس الشركات (SRL / SAS)، استخراج الرقم الضريبي (Partita IVA)، والاستشارات التجارية.
10. **10. تحصيل الديون والنزاعات المالية (Recupero Crediti)**  
    استصدار أوامر الأداء القضائي (Decreto Ingiuntivo)، والحجز التنفيذي ومتابعة المستحقات المالية.

## 🚀 المميزات التقنية والوظيفية (Features)

- **شعار وهوية بصرية مخصصة (Custom Piazza Emblem)**: تصميم هندسي دقيق مستوحى من شعار ميزان العدالة لمكتب PIAZZA للمحاماة.
- **تكامل واتساب فوري (Smart WhatsApp Integration)**: توليد رسائل مهيكلة وجاهزة تحتوي على نوع الخدمة، بيانات الموكل، والدرجة الاستعجالية للطلب بنقرة زر واحدة.
- **نموذج حجز الاستشارات (Consultation Booking System)**: يتيح للموكل اختيار الخدمة، التاريخ، الفترة الزمنية، ونبذة عن القضية وحفظ الطلب محلياً.
- **أداة الفحص القانوني السريع (Legal Eligibility Checker)**: تقييم تفاعلي فوري لملفات الجنسية، قضايا العمل، وحوادث السير.
- **دليل الأسئلة الشائعة (FAQ Accordion)**: إجابات قانونية دقيقة ومبسطة حول أهم الإشكالات والإجراءات.
- **تصميم متجاوب وسريع (Responsive & Mobile-First)**: يعمل بسلاسة فائقة على جميع الهواتف الذكية، الأجهزة اللوحية، وشاشات الحواسيب.

## 🛠️ البنية التقنية (Tech Stack)

- **Icons**: Lucide React

## 💻 التشغيل والتطوير محلياً (Local Development)

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل خادم التطوير (Run Dev Server)
```bash
npm run dev
```
سيعمل التطبيق على الرابط المحلي: `http://localhost:3000`

### 3. بناء النسخة الإنتاجية (Production Build)
```bash
npm run build
```
